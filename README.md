## PWA 安裝說明 (PWA Installation)

本網站支援 PWA (Progressive Web App)，您可以將本筆記安裝到您的裝置上，獲得更流暢的瀏覽體驗。

### 在行動裝置上 (Mobile - iOS/Android)

- **Android (Chrome)**：點擊瀏覽器右上角的菜單 (三個點)，選擇「安裝應用程式」或「加到主畫面」。
- **iOS (Safari)**：點擊底部的「分享」按鈕，向上滑動並選擇「加入主畫面」。

### 在電腦上 (Desktop - Chrome/Edge)

- 在瀏覽器網址列右側，點擊「安裝」圖示（帶有加號的螢幕或安裝按鈕），即可將網站安裝為獨立的應用程式視窗。
